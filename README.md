# Dart Exercises
My name is Nathaniel Popes, and this is my Week 7 Dart exercise for NTC_PC16 Mobile Development w/ Lab.
This program demonstrates a simple student purchase. It uses Dart variables, different data types, arithmetic operators, comparison operators, and console output.
The program uses a String for the student name, an int for the quantity, a double for the price, and a bool for the student status.
To run the program, open the project folder in the terminal and use the command `dart run`.
